# 野球メカニクスノート

野球選手を見るときに「どこを見ればよいか」を学ぶための1ページ教材です（投球・守備・打撃・走塁）。

- 投手（基礎編）／野手（基礎編）
- らすかわさん理論（note をもとに要約。投手・野手を選択して表示）
- 鴻江理論（うで体・あし体）
- みしマンさんの見方（打撃8フェーズ・投球7フェーズの観察点）
- 佐藤康さんの見方（理学療法士の視点。投球障害につながる動き）
- Namikiさんの見方（データで見る球種・球質・打者）
- テスト：総合テスト（全教材から、レベル別）と教材別テスト。1プレイ10問の4択。問題数は教材の内容に応じて変わります

`index.html` をブラウザで開くと使えます。`app.html` が本体で、編集後は `./build.sh` で `index.html` を作り直します。
